# life-mmo — 地球 Online · 角色面板

> 地球 Online · Character Sheet: answer 12 playful questions, get your game-style life character panel — attributes, title, buffs/debuffs, and the six high-player traits. Screenshot-friendly.

## Play

- Hosted: https://liyuankui.github.io/life-mmo/
- Or open `dist/index.html` directly — pure static single file, zero dependencies, no network requests.

玩法：答 12 道题 → 生成角色面板（六属性、高玩六维雷达、称号解读、Buff/Debuff、主线/支线提示、Roguelike 冒险日志）。游戏化自评，非测评；数值直接映射答案，无黑箱。

## Dev

```bash
bun install && bun test && bun run dev   # http://localhost:3142
```
